```python
# contact sheet: look at every page before sending
from PIL import Image; import glob
fs = sorted(glob.glob('<folder>/.build/booklet-pages/*.png'))
ims = [Image.open(f) for f in fs]; w, h = ims[0].width // 5, ims[0].height // 5
m = Image.new('RGB', (7 * w, ((len(ims) + 6) // 7) * h), 'white')
for k, im in enumerate(ims): m.paste(im.resize((w, h)), ((k % 7) * w, (k // 7) * h))
m.save('sheet.png')
```

إصلاحات شائعة:

```text
overflow            → split a long card/list into several cards
mismatch EN/AR      → add a full stop in the Arabic, or use the Arabic species name

bad bidi in table   → put English in its own cell or in `backticks`
```
