# 02 قواعد الأسلوب

هذه القواعد متّفق عليها مع المستخدم، وتُطبَّق على كل ملزمة جديدة. النسخة الرسمية لها في ملف التعليمات:

```text
.claude/skills/bios-malzama/SKILL.md
docs/BIOS_ENGINE_GUIDE.md
```

## المحتوى

```yaml
english:
  verbatim: true            # copy the source exactly, keep its typos and punctuation
  fixes_go_in: "BIOS note"  # N(en, ar, label=("BIOS note", "ملاحظة BIOS"))
  cut_text: "[[cut]] / [[قطع]]"
arabic:
  sentence_by_sentence: true   # every English sentence followed by its own Arabic sentence
  never_translate_paragraph_at_end: true
  inside_list_points_too: true
  checker: imm456/split.py     # save() refuses to write if sentence counts differ
tables:
  every_english_cell_translated: true   # cell = ["en", "ar"]  (helper B(en, ar))
  headers_too: true
  no_extra_translation_column: true
organise_for_memorising:
  use: [summary tables, flow arrows, lettered/numbered points, "at a glance" boxes]
  english_stays_verbatim: true
per_topic_summary:            # team rule from 2026-10-28 on
  where: end of every section
  box: 'INSHORT([(en, ar), …])   →  "In short — باختصار"'
end_of_handout:
  only: "Key terms — أهم المصطلحات"      # TERMS([(term, "ترجمة 1 / ترجمة 2 / ترجمة 3"), …])
  several_arabic_renderings_per_term: true
  # older handouts (before 2026-10-28) end with END(points, terms) = quick summary + glossary
figures:
  every_figure_has: bilingual caption
  labels_inside_figure: translated in a table under the figure
questions:
  lecturer_questions: become "important questions" with model answers
  picture_questions: yes, whenever the lecture has figures
  mcq_answers_balanced: balance(mcq, seed)
```
