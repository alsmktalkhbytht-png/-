# 08 تسليم الشغل لمحادثة جديدة

هذا الملف يُعطى لأي محادثة جديدة (سحابية أو على الحاسبة) حتى تكمل الملازم من نفس النقطة بدون ما تسأل من جديد.
اقرأه كامل، وبعده [[02 قواعد الأسلوب]] و[[05 سجل القرارات]] و[[07 المعلّق والمطلوب]].

## 1. أول رسالة يكتبها المستخدم بالمحادثة الجديدة

```text
كمّل شغل ملازم BIOS. المستودع alsmktalkhbytht-png/- والفرع claude/tender-bohr-mhayza.
اقرأ BIOS-Obsidian/08 توثيق المحادثة للجلسة المحلية.md وطبّق كل القواعد اللي بيه وبالـ vault.
```

## 2. أول شي تسويه الجلسة الجديدة

```bash
# 1) الفرع
git fetch origin claude/tender-bohr-mhayza && git checkout claude/tender-bohr-mhayza && git pull

# 2) رجّع المولّدات والأدوات لمجلد العمل (scratchpad الجلسة الجديدة)
bash BIOS-Obsidian/tools/restore_scripts.sh <scratchpad>
#    هذا ينسخ tools/scripts/* ويبدّل المسار القديم بالجديد داخل كل الملفات

#    save() يكتب إلى /home/user/- ؛ إذا المستودع بمكان ثاني:  mkdir -p /home/user && ln -sfn "$PWD" /home/user/-

# 3) أي ملزمة جديدة تبدأ هيج
#    import sys; sys.path.insert(0, "<scratchpad>/imm456")
#    from ci import *      # C R SEC H2 L N FLOW T F FF SIDE B Q TF TR IM P INSHORT TERMS balance save HEM
#    ... blocks + TERMS([...]) ... mcq = balance(mcq, seed) ... save("<folder>", meta, blocks, mcq, tf, traps, important)
#    sys.path.insert(0, "<scratchpad>"); from flowfit import fit; fit("<folder>")   ← آخر سطر: يملأ الصفحات بلا فراغات

# 4) البناء والفحص
cd bios-engine && python3 bios.py ../<folder>/lecture.json      # يطبع overflow إذا اكو
python3 -W ignore <scratchpad>/fill2.py <folder>                 # كل صفحة محاضرة ≥ 80%؛ السبب: gapdbg.py
python3 <scratchpad>/review.py <folder> <source.txt>             # ⚠ إلزامي قبل الإرسال: التدقيق (قاعدة 2026-11-06)
#    بعدها اقرأ lecture.json كامل (EN | AR) وصور الصفحات بنفسك، صلّح، أعد البناء والتدقيق — وبعدين أرسل
#    ثم contact sheet لصور الصفحات (انظر [[04 طريقة العمل]])

# 5) التوثيق والرفع
#    README.md + docs/BIOS_ENGINE_GUIDE.md + نسخ السكربت إلى BIOS-Obsidian/tools/scripts/<job>/
BIOS_SCRATCH=<scratchpad> python3 -I BIOS-Obsidian/tools/vault.py
git add -A && git commit && git push -u origin claude/tender-bohr-mhayza
```

أمثلة جاهزة للأسلوب الجديد (انسخ منها):
`tools/scripts/hl8/l8.py` (نظري طويل)، `tools/scripts/lb2/gl2.py` (عملي)، `tools/scripts/mic/mic.py` (مرحلة رابعة + دمج)، `tools/scripts/par3/p3.py` (مرحلة رابعة + ملف أسئلة منفصل + جداول كتابات الصور بعمودين).

## 4. القواعد المختصرة (التفاصيل في [[02 قواعد الأسلوب]])

```text
- الإنكليزي حرفي من ملف الأستاذ، حتى أخطاءه؛ التصحيح بـ "BIOS note — ملاحظة BIOS"
- الجدول إضافة للحفظ وليس بديلاً: النص الأصلي يبقى حرفيًا قبله (خطأ وقع في بكتريا 7–9 وتصلّح)
- الترجمة بعد كل جملة (split.py يرفض الحفظ إذا اختلف العدد؛ انتبه لـ ".. B" و"Hb. S" و"Vit. B12")
- كل خلية جدول ["en","ar"] عبر B(en, ar)، والعناوين أيضاً
- "In short — باختصار" بنهاية كل موضوع (INSHORT)، وبنهاية الملزمة "Key terms" فقط (TERMS) بعدّة ترجمات
- المرحلة 3: ثيم وردي والأسئلة مدموجة تلقائياً؛ المرحلة 4: wineoat وملف أسئلة منفصل — دائمًا (طلب المستخدم 2026-11-01)، حتى لو سبق وانعمل دمج؛ بكتريا 7–9 انفصلت
- "دمج" = merge_questions + file_name "<الاسم> - <title_ar> - دمج"
- كل صور الملف تدخل الملزمة، وكتابات الصورة تُترجم بجدول تحتها؛ صور فيها جداول → حوّلها لجدول مترجم
- سؤال الأستاذ (Quiz / pretest / posttest) → "أسئلة مهمة" بإجابة نموذجية
- افحص الصفحة الأولى: إذا بقت فارغة بسبب جدول طويل، قسّم الجدول
- راجع الملزمة على الملف: سكربت يقارن كلمات المصدر مع lecture.json (انظر آخر قسم)
- ⚠ التدقيق قبل الإرسال (طلب المستخدم 2026-11-06، لكل ملزمة بلا استثناء): بعد البناء شغّل review.py (تغطية المصدر جملة جملة،
  الكلمات الناقصة، الترجمة الناقصة، الصور غير المستعملة، مفاتيح الأسئلة وتوازنها، الفراغات) لازم يطلع "REVIEW OK"،
  وبعدها اقرأ كل lecture.json بنفسك (المعنى، الأرقام، الأسماء، حلول المسائل، كل جواب MCQ/TF، المصطلحات) وشوف صور الصفحات؛
  صلّح وأعد — وبعدين ترسل، وتذكر للمستخدم بسطر شنو تدقّق وشنو تصلّح
- لا فراغات كبيرة بالصفحات (طلب المستخدم 2026-10-31): بعد البناء شغّل
  python3 <scratchpad>/fill.py <folder>/.build/booklet-pages   ← كل صفحة بالملزمة ≥ 80%
  python3 <scratchpad>/fill2.py <folder>                        ← الأدق: صفحات المحاضرة بس (يتجاهل آخر صفحة
                                                                   قبل الأسئلة وصفحات الأسئلة المدموجة لأنها نهايات طبيعية)
  العلاج الأول (من 2026-11-06): flowfit.py — يقصّ البطاقات والملاحظات والجداول بالمكان اللي يملأ الصفحة (يقيس بالمحرك نفسه)،
  والجزء الثاني يكمل الترقيم أو يعيد رأس الجدول مع "(continued) — (تكملة)"؛ chunk_lists القديمة ما تنحتاج.
  الباقي بعده: كتابات الصور القليلة داخل عنوان الشكل بدل جدول، تصغير الصور، لا keep على الشكل+جدول طويل،
  تقسيم جدول المصطلحات إلى جداول 6 صفوف، تقسيم خطوة طويلة، حذف سهم/مخطط مكرّر
- أهم الأسئلة / المقالب: السؤال العربي يطلع فوق الجواب العربي (إصلاح المحرك 2026-11-01، model_answer q_ar)؛ الملازم القديمة تتصلّح إذا أُعيد بناؤها
- مصطلحات طلبها المستخدم: Multiple myeloma = "الورم النقوي المتعدّد" (لا تختصرها)؛ structure = "بنية / هيكل / تركيب" (لا "بناء")
- عناوين الأقسام (SEC) قصيرة؛ العنوان الكامل من الملف يُكتب H2 تحتها
- القوائم المرقّمة: R يكمل الترقيم داخل القسم (11، 12…) — للعيوب/المزايا استعمل L حتى يبدأ من 1
- قائمة L طويلة تسبّب فراغ؟ قسّمها لبطاقتين والثانية بـ start=<الرقم التالي> (bios.py يدعم "start" من 2026-11-01)
```
