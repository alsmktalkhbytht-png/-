# ذاكرة ملازم BIOS — ابدأ هنا

> هذه الخزنة (Obsidian vault) هي **الذاكرة الدائمة** لصنع ملازم قناة **BIOS** (`@BIOS0t`).
> كل التفاصيل التي اتُّفق عليها مع المستخدم، والتصميم، والكودات، والدروس المستفادة محفوظة هنا.

## متى أرجع لهذه الذاكرة؟

**دائمًا وفورًا** عندما يكتب المستخدم أيًّا من هذه العبارات (أو ما يشبهها) أو يرسل ملف محاضرة:

- «ترجم المحاضرة» / «ترجم الملزمة»
- «سوّي ملزمة» / «طبق عليه» / «مثل هذا النمط»
- يرسل ملف `PDF` أو `PPTX` أو `DOCX` ومعه: اسم المادة، نظري/عملي، رقم المحاضرة، المرحلة، التدريسي.
