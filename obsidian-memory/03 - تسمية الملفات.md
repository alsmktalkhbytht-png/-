# تسمية الملفات

## الصيغة المعتمدة (أمر المستخدم)

```
<اسم المادة المختصر> <نظري|عملي> محاضرة <الرقم>.pdf
<اسم المادة المختصر> <نظري|عملي> محاضرة <الرقم> - الأسئلة.pdf   ← للمرحلة الرابعة فقط
```

- **بدون** كلمة `BIOS`، **بدون** فواصل، والرقم **أرقام** لا كلمات.
- أمثلة حقيقية:
  - `امراض دم نظري محاضرة 1.pdf`
  - `غدد عملي محاضرة 2.pdf`
  - `مناعة نظري محاضرة 1.pdf`
  - `فايروسات عملي محاضرة 2.pdf`
  - `تقنيات متقدمة نظري محاضرة 2.pdf`
  - `انزيمات سريرية عملي محاضرة 2.pdf` + `انزيمات سريرية عملي محاضرة 2 - الأسئلة.pdf`
- المحرك يبني الاسم تلقائيًا من `meta.short_ar` + `meta.kind` + `meta.unit_no`:

```python
def file_name():
    """Arabic file name, no BIOS prefix and a plain digit: 'امراض دم نظري محاضرة 1'."""
    if M.get("file_name"):
        return M["file_name"]
    week = M["unit_ar"].startswith("الأسبوع")
    unit = f'{"الأسبوع" if week else "محاضرة"} {M["unit_no"]}'
    kind_ar = cover_kind(M.get("kind")).split(" · ")[0]
    return f'{M.get("short_ar", M["subject_ar"])} {kind_ar} {unit}'
```

- `short_ar` = الاسم الذي يستعمله المستخدم للمادة (انظر [[09 - المواد والتدريسيين]]).
- الملازم القديمة (قبل هذا القرار) أسماؤها `BIOS - ... المحاضرة الأولى` وتبقى كما هي.
- اسم مجلد المحاضرة بالإنجليزي: `<subject>-<lec|lab><N>-<topic>` مثل `immunology-lec2-immune-system`.
