# الألوان والمراحل

## القاعدة (أمر المستخدم)

> «من أگلك المادة للمرحلة الثالثة تطبق ألوان الثالثة، ومن أگلك للرابعة تطبق ألوان الرابعة.»

| المرحلة | الثيم | الألوان | الأسئلة | `meta.stage` (حرفيًا) |
|---|---|---|---|---|
| **الثالثة** | `blush` (وردي) | `#f9e9ef` · `#f2808f` · `#e8d6d0` · `#eebcc2` + نص `#4a2a30` | **داخل نفس الملف** بعد المحاضرة | `"The third stage — الثالثة"` |
| **الرابعة** | `wineoat` = **النموذج العاشر** | `#4A2C34` · `#C9B4A5` · `#F7F1EE` | **ملف منفصل** `... - الأسئلة.pdf` | `"The fourth stage — الرابعة"` |

- المحرك يختار الثيم والدمج تلقائيًا من `meta.stage` — **لا تكتب `theme` ولا `merge_questions`** إلا بطلب صريح.
- الكود المسؤول في `bios-engine/bios.py`:

```python
third = cover_stage() == "المرحلة الثالثة"
theme = M.get("theme", "blush" if third else "wineoat")      # third stage: the pink palette
merge = M.get("merge_questions", third)                       # third stage: questions inside the handout
```

- إذا لم يذكر المستخدم المرحلة: **اسأل** قبل البناء (تغيّر الألوان والدمج).

## سجل قرارات حصلت

- غدد (ثالثة): طلب مرة فصل الأسئلة، ثم طلب **إرجاعها مدموجة** → القاعدة النهائية للثالثة: مدموجة.
- تقنيات متقدمة (ثالثة): نفس الشيء، مدموجة.
- إنزيمات سريرية عملي 2 (رابعة): «لون المرحلة الرابعة النموذج العاشر» → `wineoat` + أسئلة منفصلة.
- طفيليات عملي 1 (رابعة، د. ناريمان حسن): «الـ mcq خليهن بنهاية المحاضرة لا تفصلهن» → `wineoat` + `merge_questions=True`. إذا طلب الدمج للرابعة مرة أخرى طبّقه بنفس الطريقة.

## توليد ثيم جديد (فقط بطلب)
