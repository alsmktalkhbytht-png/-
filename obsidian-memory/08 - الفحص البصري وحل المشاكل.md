# الفحص البصري وحل المشاكل

## لوحة كل الصفحات
```python
from PIL import Image; import glob
fs = sorted(glob.glob("<folder>/.build/booklet-pages/*.png"))   # الأسئلة المنفصلة: questions-pages
ims = [Image.open(f) for f in fs]; w, h = ims[0].size
ims = [i.resize((400, int(h*400/w))) for i in ims]; W, H = ims[0].size
cols = 6; rows = (len(ims)+cols-1)//cols
S = Image.new("RGB", (W*cols, H*rows), "white")
for i, im in enumerate(ims): S.paste(im, ((i % cols)*W, (i//cols)*H))
S.save("sheet.png")
```
ثم كبّر صفحتين أو ثلاثًا (عرض 900px) واقرأ النص العربي فعليًا.

## قائمة الفحص
- [ ] `no overflow` في ناتج البناء.
- [ ] الغلاف: المادة، العنوان، الرقم، النوع، المرحلة، التدريسي.
- [ ] الألوان صحيحة للمرحلة ([[02 - الألوان والمراحل]]).
- [ ] اسم الملف صحيح ([[03 - تسمية الملفات]]).
- [ ] كل جملة من المصدر موجودة، ولا شيء مضاف ([[01 - القواعد الذهبية]]).
- [ ] لا نص عربي مقلوب الترتيب حول الإنجليزي/الأرقام.
- [ ] الصور كاملة غير مقصوصة، والتعليقات مطابقة.
- [ ] لا صفحات بنصفها فارغ بلا سبب.
- [ ] توزيع الإجابات متوازن.

## مشاكل حدثت فعلًا وحلولها

| المشكلة | الحل |
|---|---|
| جملة عربية فيها اختصارات متتالية (`GHRH` يحفّز `GH`؛ ...) ينقلب ترتيبها | أعد صياغة الجملة بحيث يبدأ السطر بكلمة عربية: «يحفّز `GHRH` إفراز `GH`، ...» |
| `-70°C` داخل العربي ينقلب | اكتب «سالب 70 °م» |
| `2–8°C` داخل العربي | «من 2 إلى 8 °م» |
| عنوان قسم عربي فيه `(ALT)` = `GPT` يظهر مشوّهًا | اجعل عنوان القسم العربي بسيطًا: «ناقلة أمين الألانين `(ALT)`» |
| ملاحظة إنجليزية فيها كلمات عربية بين أقواس تظهر مقلوبة | لا تضع عربيًا داخل الحقل الإنجليزي |
| صفحة نصفها فارغ لأن بطاقة طويلة انتقلت | قسّم البطاقة/القائمة إلى بطاقتين (مثلًا قائمة 5 نقاط إلى 3 + 2) |
| صورة كبيرة مع `keep=True` تدفع جدولها لصفحة جديدة | صغّر `h` أو أزل `keep` |
| صورة تفاعل مقصوصة من طرفها | استعمل القصّة الأصلية الكاملة من `pg.images` |
| `AssertionError: en/ar sentence lists differ` | وحّد عدد عناصر القائمتين |
| `SyntaxError` بعد تعديل آلي | `python3 -c "import ast; ast.parse(open('make.py').read())"` |
| `node` لا يجد `playwright` | المحرك يضبط `NODE_PATH` بـ `npm root -g` |
| ملف أسئلة منفصل قديم بعد تغيير المرحلة | المحرك يحذفه تلقائيًا عند الدمج؛ واحذف الـ PDF القديم بالاسم القديم يدويًا بـ `git rm` |
| تغيّر اسم المادة/الملف | `git rm` للـ PDF القديم، ثم أعد البناء |

- **اسم لاتيني ينقسم على سطرين داخل العربي** (يقرأ بترتيب خاطئ): أصلحه المحرك — أي مقطع بين `` ` `` طوله 32 حرفًا أو أقل لا ينكسر (`bdi.lt.nw{white-space:nowrap}`).
- **صفحات نصف فارغة بسبب بطاقات طويلة (جمل كثيرة):** في `make.py` استعمل `split_cards(blocks, n=2)` (مثال في `parasitology-lec2-protozoa/make.py`) لتقسيم البطاقة إلى بطاقات من جملتين بلا حذف.
- **عنوان قسم طويل ينقصّ داخل الشريط** (مثل `Alanine Aminotransferase (ALT) / Glutamic-Pyruvic Transaminase (GPT)`): أصلحه المحرك — `.sb` صار `min-height:9mm` مع `padding:1mm 5mm` فيلتفّ العنوان على سطرين بدل أن ينقص (الأشرطة ذات السطر الواحد بقيت كما هي).
- **مبدأ الفحص ينفصل عن جدول تفاعلاته:** ضع `keep=True` على بطاقة المبدأ (وعلى جدول الحجوم ليبقى مع خطوات الخلط).
