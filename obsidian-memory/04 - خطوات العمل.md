# خطوات العمل الكاملة لمحاضرة جديدة

## 0. التحضير (مرة واحدة في كل جلسة)
- تأكد أن المحرك موجود: `ls bios-engine/bios.py`. إن لم يكن، فهو في الفرع الذي يحوي الملازم (اجلبه بـ `git fetch` ثم `git merge`).
- لا تشغّل `playwright install` — المتصفح موجود في `/opt/pw-browsers`.
- المجلد المؤقت: scratchpad الجلسة (لصور الصفحات واللوحات).

## 1. جمع المعلومات من رسالة المستخدم

| المعلومة | مثال | إذا غابت |
|---|---|---|
| المادة | غدد، مناعة، فايروسات | خذها من [[09 - المواد والتدريسيين]] أو اسأل |
| النوع | نظري / عملي | من رأس الملف (`Lab` = عملي) أو اسأل |
| الرقم | 2 | اسأل إن تعارض مع محاضرة موجودة |
| المرحلة | الثالثة / الرابعة | **اسأل** (تحدد الألوان والدمج) |
| التدريسي | م.م. آية وسمي | استعمل الاسم المعتمد في [[09 - المواد والتدريسيين]]؛ لا تخترع لقبًا |

- إذا أرسل المستخدم **نفس الملف** مرة ثانية (تحقق بـ `md5sum`) برقم مختلف: لا تبنِ نسخة ثانية، اسأله هل يقصد تصحيح الرقم.
- ترويسة المصدر قد تحمل اسم مادة مختلف (مثل `Clinical Biochemistry` لمادة الغدد): **اعتمد ما يقوله المستخدم**.

## 2. استخراج المحتوى
انظر [[06 - استخراج المحتوى]]. اقرأ **كل** صفحة/شريحة كصورة أيضًا للتأكد من عدم ضياع نص داخل صورة أو مخفي خلف صورة.

## 3. كتابة `make.py` في مجلد المحاضرة
- انسخ [[قوالب/make_template.py]] إلى `<folder>/make.py`.
- انقل **كل** النص بالترتيب، جملة بجملة، بدون حذف أو إضافة ([[01 - القواعد الذهبية]]).
- اكتب `meta` كاملًا (المرحلة بالصيغة الحرفية).

## 4. البناء
```bash
python3 <folder>/make.py
python3 bios-engine/bios.py <folder>/lecture.json
```
السكربت يطبع: عدد أسئلة الاختيار وتوزيع `a b c d`، وعدد الصح والخطأ وتوزيعه، والمقالب، والمهمة.
ناتج البناء يجب أن يحوي `no overflow`.

## 5. الفحص البصري
انظر [[08 - الفحص البصري وحل المشاكل]] — لوحة مصغّرات + تكبير صفحتين على الأقل + الغلاف.

## 6. الإرسال والحفظ
1. أرسل الـ PDF (والأسئلة إن كانت منفصلة) بأداة إرسال الملفات.
2. أضف سطرًا في `README.md`.
3. `git add README.md <folder>` (لا يُرفع `.build/`)، `commit` ثم `push` إلى فرع العمل.
4. حدّث [[10 - سجل الملازم المنجزة]] و[[09 - المواد والتدريسيين]] إن ظهرت مادة/تدريسي جديد.

## 7. الرد على المستخدم
انظر [[12 - أسلوب الرد على المستخدم]]: ملخص قصير، ما افترضته، وأي سؤال واحد ضروري.
