# استخراج المحتوى

> ضع الملفات المرفوعة في مجلد مؤقت مستقل، وشغّل بايثون بـ `-I` عند قراءتها.

## PDF — النص
```bash
python3 -I -c "
import pdfplumber
p = pdfplumber.open('src/x.pdf')
for i, pg in enumerate(p.pages):
    print('=== PAGE', i+1); print(pg.extract_text() or '')
    print('IMGS', [(round(o['x0']),round(o['top']),round(o['x1']),round(o['bottom'])) for o in pg.images])
"
```
- **اقرأ صور الصفحات أيضًا** (`pdftoppm -r 70 -png`) — حدث أن جدولًا مصوّرًا **غطّى** نصًّا (تطبيقات الإليزا 4–7 في غدد عملي 1): النص يظهر في الاستخراج ولا يظهر في الصورة، فيُنقل.
- الإجابات المعلّمة بالخط العريض:
```python
ws = pg.extract_words(extra_attrs=["fontname"])
print([w["text"] for w in ws if "Bold" in w["fontname"]])
```

## PDF — قصّ الصور من صورة الصفحة (أفضل طريقة)
```python
import pdfplumber; from PIL import Image
p = pdfplumber.open("src/x.pdf")            # بعد: pdftoppm -r 220 -png src/x.pdf hi
for i, pg in enumerate(p.pages):
    im = Image.open(f"hi-{i+1}.png"); s = im.size[0] / float(pg.width)
    for k, o in enumerate(pg.images):
        box = (int(o["x0"]*s), int(o["top"]*s), int(o["x1"]*s), int(o["bottom"]*s))
        im.crop(box).convert("RGB").save(f"c{i+1}_{k}.jpg", quality=92)
```
- راجع كل قصّة بصريًا: لا تقصّ جزءًا من الشكل (حدث مع `alanine` في تفاعل ALT — استعمل القصّة الكاملة).

## PPTX
```python
from pptx import Presentation
p = Presentation("src/a.pptx")
def walk(shapes):
    for sh in shapes:
        if sh.shape_type == 6: walk(sh.shapes); continue          # مجموعات
        if sh.has_text_frame:
            for para in sh.text_frame.paragraphs:
                t = ''.join(r.text for r in para.runs)
                if t.strip(): print('  '*para.level + '- ' + t)
        elif getattr(sh, "has_table", False) and sh.has_table:
            for r in sh.table.rows: print(' | '.join(c.text for c in r.cells))
        elif sh.shape_type == 13: print('[PIC]', sh.name)
for i, s in enumerate(p.slides, 1):
    print('=== SLIDE', i); walk(s.shapes)
```
- الصور: `unzip -o -q src/a.pptx 'ppt/media/*' -d media` ثم ربطها بالشرائح:
  `unzip -p src/a.pptx ppt/slides/_rels/slideN.xml.rels | grep -o 'media/[^"]*'`
- لرؤية الشرائح: `soffice --headless --convert-to pdf --outdir src src/a.pptx` ثم `pdftoppm -r 50`.
- بعض الشرائح **كل نصها داخل صورة** (التألّق المناعي): اقرأ الصور ونقل النص حرفيًا.
- عروض بأسلوب «Gamma» (المناعة 1 و2): النص في مجموعات وصناديق؛ الصور الفنية زخرفية، والمخططات الداكنة (مثل العقدة اللمفاوية، الأولية/الثانوية) فيها نص يُنقل إلى جدول.

## لوحة مصغّرات لاختيار الصور
```python
from PIL import Image; import glob
fs = sorted(glob.glob("assets/*.jpg")); H = 240
ims = [Image.open(f) for f in fs]; ims = [i.resize((int(i.size[0]*H/i.size[1]), H)) for i in ims]
W = 1900; x = y = 0; S = Image.new("RGB", (W, H*6), "gray")
for i in ims:
    if x + i.size[0] > W: x = 0; y += H + 6
    S.paste(i, (x, y)); x += i.size[0] + 6
S.crop((0, 0, W, y+H)).save("assets.png")
```

## مصدر بصيغة Markdown + صور مرقّمة (بكتريا عملي 1)
- المستخدم قد يرسل نص المحاضرة ملف `.md` فيه أماكن الصور مثل `[IMAGE 01 — PAGE 2: insert images/IMAGE_01_page_02.png here]`، والصور في ملف `zip` منفصل مع `README_image_placement.txt`.
- النص في الـ md يُعامل كالمصدر حرفيًا؛ الجداول قد تكون مشوّهة (صفوف متناوبة) فيُعاد ترتيبها بنفس الكلمات.
- قارن وصف الصورة بمحتواها الفعلي (في بكتريا عملي 1 كان وصفا الصورتين 02 و03 معكوسين) وأبلغ المستخدم.

## تنبيه: ملفات md المُعدّة بأداة أخرى
- قد تحتوي صياغة ليست من المحاضرة مثل «The source lists ...» أو «The source document lists ...» أو ملاحظات محرّر (`> ملاحظة: ...`) أو سطر `Source: ... @قناة`.
- سطر المصدر بمعرّف قناة أخرى وملاحظات المحرّر **لا تُنقل**؛ الجمل المعاد صياغتها تُنقل كما هي ويُنبَّه المستخدم ويُطلب منه الـ PDF الأصلي إن أراد النص الحرفي.
- مثال: انزيمات عملي 2 (`The source document lists GOT in ...`، والأصل في الملزمة القديمة: `decreasing concentrations of GOT are found in ...`)، وبكتريا نظري 1 (البند الخامس `The source lists obtaining ...`).

## نص ملصق + لقطة شاشة لمكان الصورة (بكتريا نظري 2)
- المستخدم قد يلصق نص المحاضرة في الرسالة ويرفع لقطة صفحة فيها الصورة مع النص قبلها وبعدها لتحديد مكانها.
- احفظ النص في `<folder>/source.txt` واللقطة كما هي، وقصّ الصورة من اللقطة (تحقّق بالنظر أن القصّة نظيفة).
- السطر المستقل في النص الملصق (مثل `Electrical safety`) عنوان؛ والفقرة التي تبدأ بكلمات مثل `Chemical safety of ...` ليست عنوانًا.

## PDF عربي بخط قديم (أخلاقيات 2)
- `pdfplumber` يُخرج حروفًا مشوّهة (مثل `تُهًنا ثايقلاخا`) لأن الخط بترميز قديم: لا تعتمد الاستخراج، اقرأ الصفحات صورًا (`pdftoppm -r 110`) وانقل النص حرفيًا.
- محاضرة عربية بالكامل: `arabic_only=True`، وكل `en` فارغ (`""` أو `[""]` لكل عنصر)، والأسئلة عربية بخيارات `["", نص]`.
