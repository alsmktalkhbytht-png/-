# سكربت التوليد `make.py`

- لكل محاضرة سكربت `make.py` **داخل مجلدها** يكتب `lecture.json` (لا نكتب JSON يدويًا).
- القالب الكامل: [[قوالب/make_template.py]]. أمثلة حقيقية جاهزة للنسخ:
  - `endocrine-lab1-elisa/make.py` (نص + صور + جدول من صورة)
  - `immunology-lec1-introduction/make.py` (محاضرة طويلة بـ `group` و`table`)
  - `virology-lab2-specimens/make.py` (أسئلة التدريسي حرفيًا أولًا، 5 خيارات)
  - `enzymology-lab2-liver-function/make.py` (مرحلة رابعة، أسئلة منفصلة)

## أي كتلة لأي محتوى

| في المصدر | الكتلة |
|---|---|
| عنوان شريحة/قسم رئيس | `SEC(en, ar)` (يُرقَّم تلقائيًا) |
| عنوان فرعي | `H2(en, ar)` |
| فقرة (جمل متعددة) | `C([جمل], [ترجمات])` |
| مقدمة + نقاط | `L([نقاط], [ترجمات], en="مقدمة", ar="...")` |
| خطوات مرقّمة | `R(en, ar)` لكل خطوة |
| بطاقة بعنوان (نوع/صنف/تاريخ) | `G(title_en, title_ar, en, ar)` |
| جدول (أو جدول داخل صورة) | `T(head, rows, ar_cols=[..], key_cols=[..], widths=[..])` |
| صورة | `F(src, en, ar, h="60mm", fit="contain")` ؛ تُبقى مع ما بعدها بـ `keep=True`؛ وإن كان تعليق المصدر مرقّمًا (`Figure (1): ...`) أضف `nonum=True` |
| صورتان | `FF((src,en,ar,h), (src,en,ar,h))` |
| سلسلة أسهم موجودة في المصدر | `FLOW([(en, ar), ...])` |
| ملاحظة/تنبيه في المصدر | `N(en, ar, ["Note","ملاحظة"])` |

## قواعد كتابة النص

- `en` و`ar` إذا كانا قائمتين **يجب** أن يتساوى طولهما، وكذلك `list_en`/`list_ar` (وإلا `AssertionError`).
- اقسم عند نهايات الجمل الحقيقية فقط (لا عند `e.g.` أو `spp.` أو `5 min.`).
- `**كلمة**` مصطلح عريض مسطّر (باعتدال)، `__E. coli__` للكائنات، `` `...` `` لكل إنجليزي/رمز داخل العربي.
- النجمة الحرفية: `\\*`.
- النص المقطوع: `[[cut]]` / `[[قطع]]`.
- عمود الترجمة في الجداول: `"**المصطلح العربي** — الشرح"` مع `ar_cols=[رقم العمود]`.

## الـ meta

```python
meta = dict(subject_en="Immunology", subject_ar="علم المناعة", short_ar="مناعة",
            unit_en="Lecture 2", unit_ar="المحاضرة 2", unit_label="LEC", unit_no="2",
            title_en="...", title_ar="...",
            kind="Theory — نظري",                 # أو "Laboratories — عملي" مع unit_label="LAB"
            stage="The third stage — الثالثة",    # أو "The fourth stage — الرابعة"
            instructor="د. أحمد داود")
```

- **لا تضع** `theme` أو `merge_questions` (المرحلة تقرّرهما).
- إذا كان العنوان العربي يحوي إنجليزيًا بين `` ` `` فقد ينقلب على الغلاف؛ الأفضل عنوان عربي خالص.
