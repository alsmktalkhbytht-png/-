# المحرك من الداخل (`bios-engine/`)

| الملف | الدور |
|---|---|
| `bios.py` | JSON → HTML → PDF (الغلاف، الترويسة، الكتل، التقسيم، الأسئلة، اسم الملف) |
| `render.js` | Chromium/Playwright: قياس ارتفاع الكتل، فحص الفيض، صور الصفحات، طباعة A4 |
| `style.css` | كل التصميم (بلا ألوان؛ متغيّرات CSS فقط) |
| `themes/*.css` | الألوان: `blush` (الثالثة)، `wineoat` (الرابعة = النموذج العاشر) |
| `make_theme.py` | توليد ثيم + شعار ملوّن |
| `art.py` | رموز الخطر الحيوي/الإشعاعي المتّجهة |
| `brand/`, `fonts/` | الشعار وخطوط Mada وAmiri Quran وPlayfair |

## المسار
```
load(json) → M (meta + DEFAULTS)
  → اختيار الثيم والدمج من meta.stage
  → render_block() لكل كتلة → items = [(html, keep_with_next)]
  → paginate(items): قياس في Chromium، توزيع على صفحات (BODY_MM = 240)
  → cover() + page() لكل صفحة
  → question_items() → paginate → صفحات الأسئلة (مدموجة أو ملف منفصل)
  → doc() → .build/*.html → node render.js pdf → PDF + .build/*-pages/*.png
```

## التنسيق داخل النص (`md()`)
```python
s = re.sub(r"__(.+?)__", r'<i class="sp">\1</i>', s)          # أسماء الكائنات
s = re.sub(r"\*\*(.+?)\*\*", r'<b class="t">\1</b>', s)       # مصطلح عريض مسطّر
s = re.sub(r"`(.+?)`", r'<bdi dir="ltr" class="lt">\1</bdi>', s)  # إنجليزي معزول داخل العربي
s = re.sub(r"\^\^(.+?)\^\^", r'<span class="mark">\1</span>', s)
```

## التقسيم التلقائي
```python
for i, (h, keep) in enumerate(items):
    need = H[str(i)]; j = i
    while keep and j + 1 < len(items):        # العنوان يُحسب مع الكتلة التي بعده
        j += 1; need += H[str(j)]
        if not items[j][1]: break
    if cur and (i in forced or h_cur + need > BODY_MM):
        pages.append(cur); cur, h_cur = [], 0.0
    cur.append(h); h_cur += H[str(i)]
```
الكتلة الأطول من صفحة لا تُقسَّم — قسّمها يدويًا في `make.py`.

## تعديلات أجريت على المحرك في هذه المحادثة
- `file_name()`: الصيغة الجديدة بلا `BIOS` ورقم بالأرقام ([[03 - تسمية الملفات]]).

> التفاصيل الكاملة: `docs/BIOS_ENGINE_GUIDE.md` (21 قسمًا).
- `style.css`: شريط القسم `.sb` يتمدّد عموديًا (`min-height`) للعناوين الطويلة (ملزمة انزيمات عملي 2).
- `figure()`: خيار `nonum=True` يلغي «Figure n. / الشكل n.» التلقائي عندما يحمل تعليق المصدر رقمه بنفسه (مثل `Figure (2 ):Autoclave bags.`).
